# Task3-library-Management

A mini Library Management System using OOP principles in Java.

# What I Did

- Created classes: Book, User, Library
- Implemented book issue and return features
- Used ArrayList to store and manage books
- Applied OOP concepts:
- Encapsulation → private fields + getters/setters
- Polymorphism → overriding toString()
- Built a menu-driven program to interact with the system
